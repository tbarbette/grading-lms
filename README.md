# Generating and marking exams at the AI era

This repository relates search for a tool that would allow to generate personalized exams and grade them more easily. 

## Generation
GenAI can answers our exams and tests easily, so most teachers go back to hand-written tests. We need to be able to handle questions sets, personnalized copies, etc more easily.

## Marking
GradeScope has not moved in 5 years. In computer science course it stills lack obvious features such as converting decimal and hexadecimal, regex matching or calling an LLM as a grading assistant.

TOOLING.md relates the state of the search.
AGENTS.md is what AI agents learned while exploring some existing tools.
